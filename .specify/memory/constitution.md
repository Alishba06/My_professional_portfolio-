# Portfolio Constitution: Immersive AI Portfolio

## Core Principles

### P1. Accessibility First (NON-NEGOTIABLE)
Every user should be able to access and understand the portfolio content regardless of ability, device, or circumstance. This includes:
- Screen reader compatibility with semantic HTML
- Keyboard-only navigation support
- Respects reduced motion preferences
- 4.5:1 color contrast ratios for text
- Focus indicators on all interactive elements
- No reliance on color alone for information

### P2. Performance & Speed
Optimized for real-world conditions with measurable targets:
- First contentful paint < 2.5s on typical broadband
- Cinematic entrance completes within 3s
- Mobile responsive with adaptive loading
- Efficient bundle sizes (<150KB gzipped initially)
- Graceful degradation for slow connections

### P3. Modular & Extensible Architecture
Designed for future growth and maintenance:
- Component-based architecture with clear interfaces
- Content-first data structures
- Future-friendly code organization
- Easy addition of new sections, projects, or scenes
- Minimal coupling between features

### P4. Visual Identity & Cohesion
Consistent dark futuristic aesthetic across all sections:
- Unified color palette: dark futuristic theme
- Premium typography with hierarchy
- Advanced animations with performance considerations
- Cohesive design system across all components
- Accessibility-compliant visual contrast

### P5. User-Centered Experience
Focus on the needs of all target audiences:
- Recruiters: Quick identity/skills assessment
- Clients: Professional project showcase
- Internship reviewers: Skills and capabilities demonstration
- General visitors: Engaging, educational experience
- Clear conversion paths through contact hub
