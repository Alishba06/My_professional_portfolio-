## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18.18+ or 20+ installed
- npm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/Alishba06/My_professional_portfolio-.git
cd My_professional_portfolio-
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_SITE_URL=http://localhost:4000
NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:4000](http://localhost:4000) with your browser.

### 5. Running Tests & Typecheck
```bash
# Run unit and extensibility test suite
npm test

# Run TypeScript compiler typecheck
npm run typecheck
```

## 🚢 Deploying to Vercel

1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com/new).
3. In **Environment Variables**, add:
   - `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY`: Your Web3Forms key
   - `GEMINI_API_KEY`: Your Gemini API key (optional for server-side AI chat)
4. Click **Deploy**! Next.js 15 builds automatically without errors.
